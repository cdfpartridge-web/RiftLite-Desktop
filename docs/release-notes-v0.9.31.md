# RiftLite Beta v0.9.31

RiftLite v0.9.31 focuses on creator discovery, flexible Prep/Notes placement, clearer matchup statistics, and a smoother account-verification experience.

## What’s new

- The home page now automatically features recent Riftbound videos from participating creators, with smarter filtering, weighting, and accurate creator attribution.
- The creator video card is larger, making better use of the available home-page space.
- **Prep/Notes** now starts at the bottom-left of the game view, can be dragged to a preferred position, and remembers that position.
- Matchup statistics now combine both captured directions of each matchup into one consistent community result, while still showing how the sample was collected.
- Email verification recovery is more reliable, with a working resend action and clearer progress and error messages.

Existing accounts, settings, matches, decks, and replay data remain intact when updating.
