# RiftLite Beta v0.9.33

RiftLite v0.9.33 improves Rift Atlas match stability and makes stuck Web Replay uploads easier to resolve safely.

## What's improved

- Searching or revealing cards in Rift Atlas no longer causes repeated match-review popups by being mistaken for a new opponent.
- **Keep local only** can now resolve duplicate queue entries when they refer to the same local Web Replay capture.
- RiftLite is more careful when matching saved capture data, preventing an earlier game's recording from being attached to a later match through stale room information.

Existing accounts, settings, matches, decks, and replay files remain intact when updating.
