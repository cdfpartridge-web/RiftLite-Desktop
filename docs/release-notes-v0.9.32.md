# RiftLite Beta v0.9.32

RiftLite v0.9.32 makes match logging more automatic and adds two new creators to the community spotlight.

## What's new

- Match review now automatically fills whether you went first or second in both Rift Atlas and TCGA Arena.
- Atlas seat detection is more resilient to current room updates and can recover the correct seat from authoritative game snapshots.
- TCGA Arena now tracks first and second player separately for each game, including best-of-three series that reuse the same game channel.
- TronIsBad and Bloody have joined RiftLite's creator spotlight, with their profiles and community links available from the Home page.

Existing accounts, settings, matches, decks, and replay data remain intact when updating.
