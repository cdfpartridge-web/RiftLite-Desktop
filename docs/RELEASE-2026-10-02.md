Windows **v0.9.80** and macOS **mac-v0.9.80** are public, non-prerelease and Latest. The user approved the completed local updates, version bump and publication for Windows and Mac.

## Source and changes

- Immutable desktop runtime: **41b7ac3d1d81646b8b2d94608d8c660df2008eec**. Both annotated release tags point to this source, which was pushed to both repositories' main branches. Later receipt commits do not change the released binaries.
- Central Recording & sharing setup, unified Replays & videos and game details, clearer account/groups/invitations, scrollable Discord destination selection, upload recovery and Keep local actions, and compact Play recording indicators.
- Matches → Needs review makes deferred reviews visible across seasons and keeps explicitly opened reviews under user control until saved or deferred.
- Automatic local crash diagnostics with export; native crash upload remains disabled. No release verification modified user matches, preferences, memberships or Discord messages.
- Performance fixes remove repeated upload-parent SQL reads, replay search rebuilding, repeated legend alias preparation and premature replay processing. Controlled before/after measurements and scope are in [the implementation receipt](./RECORDING_SHARING_REFRESH.md).
- Added 22 Radiance prints from the 1 October audit, including Mordekaiser and three battlefields. Registry: 1,299 total prints, including 110 Radiance. [Card audit](./CARD-SCAN-2026-10-01.md).
- Opening Turns Lab and Replay Coach remain Coming soon. Existing app/profile/protocol/updater identity is preserved. [Customer notes](./release-notes-v0.9.80.md).
