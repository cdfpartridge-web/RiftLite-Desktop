# RiftLite v0.9.79

- Added 88 revealed Radiance card prints to capture, deck tools and replays, including six new legends, five battlefields, Bomb tokens, alternate art and signed prints.
- New legends: Ekko, Ziggs, Orianna, K'Sante, Seraphine and Jarvan IV.
- New battlefields: Cosmic Vista, Durand Memorial, Packed Amphitheater, Rakelstake and Ruined Monastery.
- Private teams now support invitations by RiftLite handle or a single-use link. Join or decline addressed invitations from Teams, and manage memberships on My Teams.
- Hub invitations now require an explicit Join action and preserve existing admin roles. Discord verification explains hub membership separately from optional server roles.

Radiance includes cards revealed as of 30 September 2026. Further previews will be added in later catalog updates. Existing replay identities and artwork remain supported.
