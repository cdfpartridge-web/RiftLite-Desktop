# RiftLite v0.9.81 release — 5 October 2026

Windows **v0.9.81** and macOS **mac-v0.9.81** are public, non-prerelease and Latest. The user authorized a version bump, rebuild and release of the finished updates. The supporting website was deployed before desktop publication.

## Source and changes

- Immutable desktop runtime: **dd70a77251075df7580beee3edb92cd37fc9a97d**. Both annotated release tags point to this commit, pushed to both repositories' main branches. Later documentation commits do not change the released binaries.
- Existing uploaded replays have an explicit Change visibility action, with Public, Unlisted and Private choices. The website editor recognizes desktop's authenticated session. Future defaults no longer rewrite healthy completed uploads, and automatic Discord delivery preserves the current visibility and stops for Private replays. [Implementation and validation](./REPLAY-VISIBILITY-2026-10-05.md).
- Desktop Known opponent hand recognizes modern per-card reveal flags, remembers concealed known cards, removes known departures and handles reconnects without including unknown draws. [Implementation and validation](./KNOWN-OPPONENT-HAND-2026-10-03.md).
- Added **66 verified prints**: 40 Radiance and 26 older alternate, promo and token prints. The registry contains **1,365 prints**, including **150 Radiance** and **148 legend prints**. Includes Evelynn, signed Mordekaiser, new battlefields and recognition of alternate/signed legend images. [Card audit](./CARD-SCAN-2026-10-05.md).
- Opening Turns Lab and Replay Coach remain Coming soon. App, profile, protocol and updater identities are unchanged. [Customer release notes](./release-notes-v0.9.81.md).
