# RiftLite v0.9.83 release — 13 October 2026

Windows **v0.9.83** and macOS **mac-v0.9.83** are public, non-prerelease and Latest. The user confirmed the local Atlas sign-in fix worked, then authorized the version bump and live update.

## Source and scope

Immutable runtime: **b48b7854d8b024bbc8bb1401b831680ea0a1be88**, pushed to both desktop repositories. Both new annotated release tags resolve to this commit. Later documentation commits do not change the binaries.

Atlas's new account OAuth callback stays in RiftLite's Atlas session instead of opening in the system browser and losing the initiating state cookie. Only exact main-site auth routes gain navigation permission; game capture/IPC trust, existing profiles and simulator isolation are retained. The separate Clerk-dependent match-history refresh migration remains outstanding. [Technical details](./ATLAS-AUTH-2026-10-13.md) and [customer notes](./release-notes-v0.9.83.md).

The website required no deployment: its three download buttons already use GitHub Latest links. All three now resolve to v0.9.83. Opening Turns Lab, Replay Coach, Android, Your Move and all prior candidates remain unchanged.
