## Source and scope

- Immutable release source: **`3f9bde3823560e87228f5222de708306c9349025`**. Both annotated tags point to this commit.
- Windows x64, Mac Intel/x64 and Mac Apple Silicon/arm64 share the same source and Electron 39.8.10.
- My active deck / Match deck in Mulligan Lab now generates ungraded practice hands from the exact saved deck. Correct Chosen Champion setup, actual card quantities, redraws and unlimited fresh hands; no community fallback or other-deck substitution.
- Game log in desktop match history reads retained Atlas text, with search, copy, per-game selection and history retained beyond Atlas's rolling live-log window. Availability follows existing capture retention.
- Date/date-range filters for matches, replays and reports.
- Valid Mulligan training packs no longer fail solely because server and desktop catalogs contain different total print counts. Per-card, deck, evidence and privacy validation remain strict.
- Fresh Atlas Game 1 boundaries cannot merge with stale captures from a previous room.
- Package, lockfile root versions, runtime identity, tests, in-app highlights and customer notes are 0.9.76. Dependency versions are unchanged.
- Customer notes: [release notes](./release-notes-v0.9.76.md) and [plain text](./RiftLite-v0.9.76-Whats-New.txt).

The release source commit contains 36 explicit implementation, test and customer-note paths. Existing Android, Your Move, other handovers, temporary work and earlier installers remain preserved. No website deployment, Android publication or installation into the user's profile was performed.
