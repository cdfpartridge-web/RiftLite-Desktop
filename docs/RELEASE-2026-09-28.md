# RiftLite v0.9.78 release — 28 September 2026

Windows **v0.9.78** and macOS **mac-v0.9.78** are public, non-prerelease and Latest. The user authorized a version bump, rebuild and deployment for Windows and Mac with the Atlas history traffic fix.

## Source and changes

- Immutable source: **1c8c49d61a262879c48ca67a64c38801ecfb5f5d**. Both annotated release tags point to this commit.
- Automatic imports share one paginated history scan for up to three matches, stop past the relevant date and skip completed/private game attachments.
- Background passes are at least two minutes apart. Increasing retry delays end after eight normal attempts per app session, with at most two additional attempts for corrected match evidence. The absolute 24-hour cutoff also applies after restarting the app.
- Opening match details no longer bypasses the retry limits. Explicit Get Atlas decks / Refresh remains available for missing or older results.
- Exact match identity, ambiguity checks, private-deck handling and account-switch protection remain enforced. The owner's deck stays readable when the owner enabled opponent-facing privacy.
- Package, lockfile root, build identity, version tests and in-app highlights read 0.9.78. Dependencies and profile identity are unchanged.
- Customer notes: [release notes](./release-notes-v0.9.78.md) and [plain text](./RiftLite-v0.9.78-Whats-New.txt). [Implementation details](./ATLAS-HISTORY-THROTTLE-2026-09-28.md).
