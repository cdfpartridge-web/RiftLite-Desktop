# RiftLite v0.9.90

- Open **Learn Riftbound** in the left menu to start with the basics, play through 40 guided lessons, practise 28 keywords and try 51 optional quiz questions. Your path remembers where you left off and shows which lessons you have already completed.
- Review a best-of-three in Atlas with clearer per-game data status. RiftLite keeps recording through the deciding game's confirmation prompt. In shared replays, **All cards** uses the available game data and lets you see which games still need an export.
- Keep live notes and decision markers with the right deck. A failed save preserves the draft for another try. Phone Scorepad imports also preserve edits when a delivery is retried.
- Recording and Sharing now makes it easier to see what is captured and shared. Account sync handles interrupted requests and keeps recoverable backups. Community Spotlight also includes Nack.
